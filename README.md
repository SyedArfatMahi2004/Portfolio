# Syed Arfat – Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Run locally
1. Open this folder in VS Code.
2. Install the "Live Server" extension, right-click `index.html` and choose "Open with Live Server".

## Avatar
The hero uses a cartoon boy drawn as inline SVG in `index.html` (search for `class="boy"`).

## Edit content
- Text and projects: `index.html` (copy the dashed "Your project name" card for each project).
- Colors: the variables at the top of `style.css`.

## Deploy
1. `git init && git add . && git commit -m "Portfolio"`
2. Create a GitHub repo and push.
3. On vercel.com choose "Add New Project", import the repo, and click Deploy. No settings needed.
